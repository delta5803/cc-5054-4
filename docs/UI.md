# 块预测实验界面说明

图形界面是块预测实验的主入口。命令行只作辅助（生成文件、无头对比），见
[README](../README.md#命令行辅助)。

## 启动

```bash
npm start
```

在浏览器打开 `http://localhost:4173/src/ui/index.html`。必须经 HTTP 访问，因为页面
使用 ES 模块；直接双击 HTML 以 `file://` 打开会被浏览器的模块加载策略阻止。

页面加载后会自动以默认参数（平移纹理、64×48、6 帧、全搜索、QP 24、半径 12）编码
一次，因此打开即有画面，不会空白。

## 布局与操作

### 左侧：实验参数

- **测试序列**：平移纹理 / 遮挡显露 / 超范围运动。切换后提示会说明该场景考察什么。
- **宽度 / 高度 / 帧数**：8..256 × 8..192，2..24 帧。所有尺寸都受解码器边界处理
  支持（非 8 倍数、单块、单行均可）。
- **搜索策略**：全搜索 / 同心螺旋 / 菱形细化。
- **量化 QP**：0..51，影响 λ 与量化步长。
- **搜索半径**：0..64，限制矢量范围。
- **使用三分量 (R/G/B)**：勾选后按三平面编码，否则只编码亮度。
- **编码并重建**：以当前参数编码，并在浏览器内立即对字节流解码校验。
- **下载 .bmpp**：把当前字节流存为文件，可用命令行 `decode` 独立验证。

### 结果区（右侧）

顶层告警条（`异常由界面提示`）会在以下情况出现：

| 类型 | 触发条件 | 含义 |
|------|----------|------|
| 成功 | 编码完成且编解码逐像素一致 | 正常完成 |
| 警告 | 运动矢量落在搜索窗口边界 | 真实位移可能超出范围，预测受限 |
| 警告 | 帧间块平均 SSD 偏高 | 运动补偿效果有限 |
| 信息 | 存在 SAD 高于静止候选的矢量 | 选择由率失真驱动，而非最小像素差 |
| 信息 | 帧间帧内有块选了帧内 | 无匹配参考（如遮挡显露）时的正确回退 |
| 错误 | 编码或解码抛异常 / 首帧出现帧间块 | 内部错误，界面显示消息而非画面 |

**逐帧浏览**：滑块、上一帧/下一帧按钮、帧缩略条，或用键盘 ←/→。默认停在第一个
**有参考帧**的帧（第 2 帧），以便预测与残差视图立即有意义。

**四视图**：

- 当前源帧：带 8×8 网格与当前选中块。
- 解码重建：来自 `decodeVideo(bytes)` 的实际输出，叠加该帧的运动矢量场。
- 预测块（参考重建）：整帧预测，由编码器为每个块记录的预测值拼接而成；帧间块为
  运动补偿结果，帧内块为 DC 预测。选中块上画出其运动矢量。
- 预测残差：`源 − 预测` 的有符号伪彩图（正为红、负为蓝），即送进变换的信号。

**块检查器**：

- 在任一画面上点击可选中 8×8 块；也可用「上一个块 / 下一个块」遍历。
- 四宫格：源块 / 预测块 / 残差 / 重建块，均为该块真实数据。
- 事实行：模式、运动矢量、SAD、静止 SAD、块比特（及其中向量/系数比特）、SSD、
  候选数、搜索模式、率失真代价、帧内代价、帧间代价。
- **被搜索候选**：散点图横轴 `mvx`、纵轴 `mvy`，点色由低到高从蓝到红表示率失真
  代价，黄圈为最终选择；下方表格按代价升序列出前 40 个候选的 MV、SAD、向量比特、
  RD 代价与选中标记。首帧或帧内块会说明无搜索发生。

**搜索策略对比**：按钮"对比全部策略"在同一序列、同一 QP 与半径下依次运行三种策略，
列出块匹配次数/帧、字节数、bpp、PSNR、RD 代价与编码耗时。所有数字来自真实编码与
真实解码重建。RD 代价最低的一行高亮。

**码流与完整性**：文件字节、magic、版本、几何、帧数、payload 位、CRC32、码率、
向量/系数比特、块模式统计、候选评估总数，以及头部 32 字节十六进制转储。

## 为什么界面结果可信

- 重建画面是 `decodeVideo(bytes)` 的输出，不是原帧。
- 预测与残差来自编码器实际使用的预测值，并已记录进块数据。
- 候选图与表来自带 `recordCandidates` 的真实搜索，代价用与写出比特流相同的码字
  函数计算。
- 一旦编解码不一致，界面直接报错，不会显示"看起来对"的图。

## 常见操作流程

1. 选场景与参数，点「编码并重建」。
2. 读顶部告警了解该配置的局限（边界钳制、帧内回退等）。
3. 在画面上点一个块，观察候选分布与最终矢量；比较"静止 SAD"与"SAD"判断选择
   是否由比特成本驱动。
4. 点「对比全部策略」，看计算量与率失真的取舍。
5. 更换策略或半径再编码，对比告警与统计的变化。
